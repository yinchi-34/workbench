# 代码审查

- **用途**：让 AI 对一段代码做审查，找出 bug、可读性和性能问题
- **适用模型**：通用
- **变量**：
  - `{{language}}` —— 编程语言
  - `{{code}}` —— 待审查的代码

## 提示词

```
你是一名资深的 {{language}} 工程师。请审查下面的代码，按以下顺序输出：

1. 正确性问题（可能导致 bug 的地方），说明触发条件
2. 可读性与命名问题
3. 性能问题
4. 修改建议（给出修改后的代码片段）

只指出真实存在的问题，没有问题的部分不必评论。

代码：
{{code}}
```

## 示例 / 备注

- 代码较长时，可以先说明这段代码的背景和预期行为，审查会更准确。
