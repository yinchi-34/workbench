# 功能类型：前端交互

适用于选区、浮层、拖拽、富文本渲染等以交互逻辑为主的功能。

## spec 中须明确的内容

| 项目 | 须回答的问题 |
|------|--------------|
| 交互流程 | 触发方式、中间状态、完成与取消的条件，建议以状态列表描述 |
| 位置基准 | 位置以哪种文本为准（渲染后的纯文本，还是原始 Markdown）；两者不一致时如何处理 |
| 边界情形 | 选区跨越多个元素、落在按钮或不可选区域、内容为空或超长时的处理 |
| 适用范围 | 哪些内容允许交互（例如是否允许引用用户本人的消息） |
| 移动端 | 长按、触摸选择与桌面端的差异；是否在本阶段支持 |
| 对后端的需求 | 需要后端额外提供的字段或返回格式，写入 spec 的"前端反馈"一节 |

## 必备验收测试

- 正常交互流程的组件测试
- 跨元素选区、空选区、超长选区等边界情形
- 不允许交互的区域不出现操作入口
- 渲染前后的位置换算结果正确
