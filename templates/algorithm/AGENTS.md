## 评审重点

GitHub 上的 Codex 评审只读本文件，不读技能，所以评审重点在这里写一份摘要：

- 结果是否正确，边界用例（空、单元素、重复、负数、溢出）是否覆盖。
- 复杂度是否与注释一致，是否有明显更优的写法。
- 测试是否真的断言了结果。
- 按严重程度分级给出问题，带文件和行号。
