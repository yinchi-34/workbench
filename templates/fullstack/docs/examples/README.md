# 输出示例

以下示例均取自划词引用聊天应用，作为各角色输出格式的参照。角色 prompt 中"格式参照 docs/examples/xxx.md"即指本目录。用于其他项目时保留格式，内容可替换为本项目的实际内容。

| 文件 | 对应输出 |
|------|----------|
| spec.md | product-manager（系统设计部分） |
| plan.md | planner 的任务说明 |
| executor-report.md | executor 的完成报告 |
| review-report.md | reviewer 的审查报告 |
| db-review.md | 数据库专项审查报告 |
