# 输出示例

都取自划词引用聊天应用，给各角色当样板。角色 prompt 里写的"格式参照 docs/examples/xxx.md"指的就是这里。换项目时保留格式，内容可以换成本项目的。

| 文件 | 谁的输出 |
|------|----------|
| spec.md | product-manager（系统设计部分） |
| plan.md | planner 的任务说明 |
| executor-report.md | executor 的完成报告 |
| review-report.md | reviewer 的审查报告 |
| db-review.md | 数据库专项审查 |
