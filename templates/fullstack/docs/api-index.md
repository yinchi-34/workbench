# 接口影响索引

改动一个接口前先查这里，弄清会牵连到哪里，再动手。每个功能的 spec 定稿后，由后端负责人同步更新。

- **层级**：对外接口 / 内部接口 / 基础能力。层级越低，被依赖得越多，改动风险越高。
- **改动规则**："谁依赖它"一栏的每一项都要检查，写进影响说明。牵连到对外接口的，按契约变更处理，必须人批准。

| 接口 | 所属功能 | 层级 | 依赖谁 | 谁依赖它 |
|------|----------|------|--------|----------|
