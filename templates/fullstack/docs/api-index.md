# 接口影响索引

修改任一接口前须先查阅本索引，明确受影响的范围后再进行修改。每个功能的 spec 定稿后，由后端负责人同步更新。

- **层级**：对外接口 / 内部接口 / 基础能力。层级越低，依赖方越多，修改风险越高。
- **修改规则**：须逐项检查"谁依赖它"一栏，并写入影响说明。涉及对外接口的，按接口契约变更处理，须经人工批准。
