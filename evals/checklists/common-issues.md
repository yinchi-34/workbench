# 常见问题清单（持续更新）

用于收尾验收的清单检查和专项审查。并非每项都适用，按改动内容选取相关条目核对；已核对的条目均须写明结论，不适用的条目注明"不适用"。

业务仓库将本文件复制为 docs/checklist.md，项目特有的问题追加在后面；通用问题回写至本文件。

## 数据库

- [ ] N+1 查询：循环中是否逐条查询数据库
- [ ] 外键与级联删除是否实际生效（SQLite 须在每个连接上执行 `PRAGMA foreign_keys = ON`）
- [ ] 事务边界是否正确：需同时写入的数据处于同一事务中，出错时返回错误而非仅记录日志
- [ ] 时间是否统一使用 UTC

## 并发

- [ ] 共享数据是否加锁，加锁顺序是否可能导致死锁
- [ ] goroutine 或线程能否正常退出，是否存在泄漏
- [ ] SQLite 并发写入是否会出现 database is locked 错误

## 幂等性

- [ ] 重复提交或重试是否会产生重复数据（例如连续两次点击发送）

## 缓存（Redis）

- [ ] Lua 脚本是否保证原子性
- [ ] 是否有针对缓存雪崩、穿透、击穿的防护措施
- [ ] 缓存与数据库之间的一致性

## 接口与安全

- [ ] 资源归属校验：是否可能访问他人的数据（例如跨会话引用）
- [ ] 是否限制输入的长度与数量，是否校验前端传入的数据，是否避免直接采信前端计算的位置
- [ ] 修改接口前是否查阅 docs/api-index.md，并检查了"谁依赖它"一栏的全部条目

## 流式与长连接

- [ ] 客户端断开后，服务端是否及时释放资源（context 取消后 goroutine 退出）
- [ ] 超时或出错时消息状态是否正确，不会长期停留在 pending / streaming

## 前端

- [ ] 跨元素选区、Markdown 渲染前后的文本位置是否一致
- [ ] 选区落在按钮或用户自身消息上时，处理方式是否符合 spec
- [ ] 移动端长按选择及边界输入

## 测试本身

- [ ] 测试是否实际断言了结果，而非仅检查未报错
- [ ] 是否存在被放宽的断言，或被跳过、删除的测试
- [ ] 是否覆盖异常与边界情况
