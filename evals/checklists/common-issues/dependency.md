# 四、依赖层

模块之间、前后端之间、与外部服务之间的依赖关系。

## 模块依赖

- [ ] 是否引入循环依赖；分层是否被跨越（例如处理层直接操作数据库）
- [ ] 新增的公共函数或类型是否有其他模块依赖，修改是否波及它们

## 接口契约

- [ ] 修改接口前是否查阅 docs/api-index.md，并逐项检查"谁依赖它"一栏
- [ ] 实现是否与 spec 中的 API 设计一致（字段名、类型、错误码）
- [ ] 前端使用的 mock 是否与真实接口一致

## 第三方服务（含大模型 API）

- [ ] 调用是否设置超时；失败时是否有重试上限与退避
- [ ] 限流、配额耗尽、服务不可用时的降级行为是否明确
- [ ] 密钥是否从环境变量读取，而非写入代码

## 版本与兼容

- [ ] 新增依赖是否必要，版本是否固定
- [ ] 升级依赖是否检查了不兼容变更
