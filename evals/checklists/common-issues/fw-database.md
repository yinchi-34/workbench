# 三、框架与中间件层：数据库

## 通用条目

- [ ] N+1 查询：循环中是否逐条查询数据库；列表接口是否批量加载关联数据
- [ ] 事务边界是否正确：需同时写入的数据处于同一事务中，出错时返回错误而非仅记录日志
- [ ] 查询条件与排序字段是否有合适的索引
- [ ] 外键与级联删除是否实际生效
- [ ] 数据库连接、语句、结果集是否及时关闭

## SQLite 特有

- [ ] 是否在每个连接上执行 `PRAGMA foreign_keys = ON`，否则外键与级联不生效
- [ ] 并发写入是否会出现 database is locked 错误；是否启用 WAL 并设置 busy_timeout
- [ ] 驱动选择是否明确（纯 Go 实现或依赖 cgo），是否影响交叉编译
