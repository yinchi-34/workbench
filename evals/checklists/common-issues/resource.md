# 五、资源开销层

从计算、网络、存储三方面核对实际开销，并与 spec 中的"资源开销估算"对照。超出估算的，回到 spec 更新估算或调整设计。

## 计算

- [ ] CPU 密集操作是否在请求路径上同步执行
- [ ] 同时运行的 goroutine 或线程数量是否有上限
- [ ] 大模型 token 消耗：单次请求的输入与输出 token 是否在估算范围内；拼接上下文（例如引用内容）是否有长度上限

## 网络

- [ ] 完成一次用户操作所需的请求次数，是否存在可合并的请求
- [ ] 单次请求与响应的数据量，是否返回了不需要的字段
- [ ] 长连接数量是否在估算范围内，空闲连接是否及时关闭
- [ ] 第三方 API 的调用次数与带宽

## 存储

- [ ] 每日新增数据量与一年后的总量是否在估算范围内
- [ ] 新增索引带来的存储与写入开销
- [ ] 日志量：是否在高频路径上输出大段日志
