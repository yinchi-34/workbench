# 常见问题清单（持续更新）

用于收尾验收的清单检查和专项审查。清单按七个层次组织，自上而下从业务需求逐步深入到技术实现与运行环境。其中语言层与框架层按技术栈拆分为独立文件，只阅读项目实际使用的技术栈。

| 层次 | 文件 | 关注内容 |
|------|------|----------|
| 一、功能层 | [feature.md](feature.md) | 需求本身的问题：边界情形、权限与资源归属、输入校验、幂等、状态一致性 |
| 二、语言层 | [lang-go.md](lang-go.md)、[lang-typescript.md](lang-typescript.md) | 语言特性引起的问题：错误处理、并发、类型、异步 |
| 三、框架与中间件层 | [fw-gin.md](fw-gin.md)、[fw-vue.md](fw-vue.md)、[fw-database.md](fw-database.md)、[fw-redis.md](fw-redis.md) | 框架与中间件的使用模式：中间件顺序、响应式、N+1 查询、缓存防护 |
| 四、依赖层 | [dependency.md](dependency.md) | 模块之间、接口契约、第三方服务、版本兼容 |
| 五、资源开销层 | [resource.md](resource.md) | 计算、网络、存储三方面的开销，与 spec 中的估算对照 |
| 六、测试本身 | [testing.md](testing.md) | 测试是否有效：断言、覆盖、是否被修改 |
| 七、运行环境 | [runtime.md](runtime.md) | 配置、密钥、数据迁移、日志与监控 |

## 使用方法

- 并非每项都适用，按改动内容选取相关条目核对；已核对的条目均须写明结论，不适用的条目注明"不适用"。
- 业务仓库将本目录复制为 docs/checklist/：本文件与功能层、依赖层、资源开销层、测试本身、运行环境五个文件全部复制；语言层与框架层只复制项目使用的技术栈文件，并删去本文件索引中未复制的条目。
- 项目特有的问题追加在对应文件末尾；通用问题回写至 workbench。新技术栈按 `lang-<语言>.md`、`fw-<框架或中间件>.md` 命名新增文件。
