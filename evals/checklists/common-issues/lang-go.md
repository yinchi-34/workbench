# 二、语言层：Go

## 错误处理

- [ ] 错误是否被忽略（`_ =`、未检查的返回值）或仅记录日志而未返回
- [ ] 包装错误时是否使用 `%w`，调用方是否用 `errors.Is` / `errors.As` 判断

## 并发

- [ ] goroutine 能否正常退出：是否监听 `context` 取消或有明确的结束条件，是否存在泄漏
- [ ] 共享数据是否加锁，加锁顺序是否可能导致死锁；是否以 `go test -race` 检查
- [ ] channel 的关闭方是否唯一，是否存在向已关闭 channel 发送的可能

## 常见陷阱

- [ ] 向 nil map 写入
- [ ] 切片共享底层数组：截取后追加是否意外修改原数据
- [ ] 循环中的 `defer` 是否导致资源延迟释放
- [ ] `context` 是否沿调用链传递，而非在中途新建 `context.Background()`
- [ ] 时间是否统一使用 UTC
