# 三、框架与中间件层：gin

## 请求处理

- [ ] 中间件顺序是否正确（例如鉴权在业务处理之前、恢复中间件在最外层）
- [ ] 写出错误响应后是否 `return` 或 `c.Abort()`，避免继续执行
- [ ] 请求绑定是否声明了校验规则（`binding` 标签），绑定失败是否返回 400
- [ ] 在 goroutine 中使用上下文时是否先 `c.Copy()`

## 流式

- [ ] SSE 是否设置正确的响应头，并在每次写入后刷新
- [ ] 是否监听 `c.Request.Context().Done()`，客户端断开后停止生成并释放资源
- [ ] 超时与出错时，是否向客户端发送明确的结束事件
