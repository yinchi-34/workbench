# 三、框架与中间件层：Vue 3

## 响应式

- [ ] 解构 `reactive` 对象或 props 是否导致响应式丢失（应使用 `toRefs` 等）
- [ ] `watch` / `watchEffect` 的依赖是否正确，是否存在重复触发或死循环

## 生命周期与资源

- [ ] 组件卸载时是否移除事件监听（例如 `selectionchange`、`resize`）与定时器
- [ ] 进行中的请求在组件卸载后是否取消或忽略结果

## 渲染与安全

- [ ] 使用 `v-html` 渲染 Markdown 时是否经过消毒，防止 XSS
- [ ] 列表渲染的 `key` 是否稳定且唯一
- [ ] 跨元素选区、Markdown 渲染前后的文本位置是否一致；移动端长按选择是否可用
