# 测试点清单：算法类

写验收用例时从这里挑测试点。不是每条都要测，挑和题目相关的。

## 输入规模

- [ ] 空输入（空数组、空字符串、nil 链表/树）
- [ ] 单元素
- [ ] 两个元素
- [ ] 题目给出的最大规模（确认不超时）

## 取值

- [ ] 负数、零
- [ ] 最大值、最小值，计算过程是否溢出
- [ ] 重复元素、全部相同
- [ ] 已排序、逆序

## 结构

- [ ] 链表：只有头结点、环
- [ ] 树：只有根、单边树（退化成链表）、完全二叉树
- [ ] 图：不连通、自环、重边

## 结果

- [ ] 无解时的返回值符合题目约定
- [ ] 多解时题目是否要求特定顺序
- [ ] 复杂度与注释一致
