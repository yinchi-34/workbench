# 跨项目记录

各业务仓库的进度、问题与效果数据统一汇总在本目录，用于跨项目查看进度、避免重复踩坑，以及对比不同工具、模型和技能版本的效果。记录由 retro 技能在每个功能完成或中止后更新，也可手动维护。

| 记录 | 文件 | 粒度 | 用途 |
|------|------|------|------|
| 进度汇总 | [progress.md](progress.md) | 每个功能一行，随阶段更新 | 查看所有项目的功能处于哪个阶段 |
| 问题索引 | [issues.md](issues.md) | 每个问题一行，只追加 | 跨项目查找同类问题，追踪是否已回写清单 |
| 基线数据 | [../prompts/results/baseline.csv](../prompts/results/baseline.csv) | 每个任务一行，只追加 | 对比工具、模型、技能版本的效果 |

## 与业务仓库的分工

- 业务仓库保留原始资料：spec、任务列表、docs/notes/ 中的详细问题记录、PR 与看板。
- 本目录只保存汇总与索引，详细内容以链接指向业务仓库，不重复保存。
- 通用问题在问题索引中登记后，回写至 [常见问题清单](../checklists/common-issues/README.md)。

## 维护规则

- 数据无法获取时留空，并在备注中说明原因，不得估算补齐。基线数据用于对比，估算值会使对比失去意义。
- 更新本目录与修改其他文件相同，通过分支与 PR 提交。
